# 案例复盘：把「整章判成空白」的翻车与重抓

> 场景：接手一份钉钉文档 PRD（`Nora软件PRD - 通讯`，文档自称 7581 字），要求拆解成测试上手手册。
> 结果：第一版手册里，**第 5 章「群聊」被标成"正文空白、不进验收清单"** —— 用户一句
> 「第 5 章群聊的，我看有内容呀？你确认你认真看过和分析过需求了吗？」把整个结论打翻。

## 一、错误是怎么发生的（4 步走偏）

1. **拿错参照物**：没看文档右上角的"7581 字"字数统计，改用"抓到 10008 字符"作为完成标准 —— 分母错了，后面全错。
2. **用了看似有效、实则无效的手段**：把预览 iframe 的 height 撑到 30000px，`innerText` 从 1795 涨到 10008，于是**误以为拿到全文**。
   - 真相：撑高只放大视口；虚拟列表仍只渲染头部块。而且页面高度会跟着继续长，**渲染进度 ≠ 文档结尾**。
3. **没有对"空章节"做截图验证**：第 5 章 `innerText` 只有三级标题，就断定"没写需求"。
4. **整轮没有打开过文档里的任何一张图** —— 而 PRD 声称有 5 张流程图，全部漏掉。

## 二、修复过程（踩坑顺序，含无效尝试）

1. 重新打开文档标签，撑高到 120000px → 内容**反而崩掉**，只剩 535 字符。
2. 逐步扫 4000 → 120000px，全是 535 字符 —— **`document.visibilityState === 'hidden'`，窗口在后台，iframe 根本没渲染**。
3. `osascript -e 'tell application "Google Chrome" to activate'` 拉到前台 → 120000px 下拿到 10168 字符，但**搜"自动建群"仍是 false**（说明还是不全）。
4. 滚动 36 屏收集 → 51277 字符，依然搜不到"自动建群"。
5. 搜穿 Shadow DOM（找到 `WPS-TRANSLATE-ENTRY`，18 万字符，确认是无关 CSS 噪声）。
6. `TreeWalker` 深度遍历（含 Shadow DOM）搜关键词 → **NOT FOUND**。
7. **截图验证 → 内容明明可见！** 由此确认：**第 5 章完全以图片承载**。
8. 滚动扫描收集到 45 个 img，`curl` 下载全部 0 字节 → 改用 huashu-chrome 的 `fetch`（binary: true + savePath）成功下载 22 张。

## 三、重抓后挖出的东西

**第 5 章群聊完整需求**（原本被判"空白"）：
- 建群方式：家长绑定手表成功后**自动创建**，初始成员 = 主管理员 + 当前孩子（2 人）
- 群名规则：【孩子昵称】的家庭群；多孩子**不能同群**
- 群头像：APP 端 2–9 人，**超 9 人不显示**；表端 2–4 人
- 成员上限 20；**不能新建/删除群、不能增删成员**
- 支持系统消息、投诉群聊（5 类原因 + 图片 0/5 + 文字 0/200）
- 二期边界：支持相机与图库，**不支持语音和视频**（图上用红叉标注）
- 图上批注：「20260917 刘缘老师评估是否可以展示拼接的图片」→「刘缘：不能拼接哦」→ **未闭环项**

**4 条"正文 vs 图片"冲突**（全部升级为 P0 阻塞项）：
| # | 冲突 | 两侧说法 |
|---|---|---|
| 1 | 自动接听时延 | 图内正文 15 秒 / 图内标题 10 秒 / PRD 正文 10 秒 |
| 2 | 禁用时段行为 | 正文"仅能拨 SOS、家长与 110/120 可呼入" vs 交互稿"禁止接听所有电话和消息、可联系家长" |
| 3 | 短信分类命名 | 正文"其他短信" vs 手表实拍"话费流量短信" |
| 4 | 内容安全结构 | 正文拆成 2.2.3 聊天守护 + 第 6 章图文音过滤 vs 交互稿"内容安全 → 微聊安全守护 + 短信安全守护" |

**顺带修掉的其他问题**：短号/亲情号（5–12 位，正文完全没提）、拦截记录保留近 30 天、"来源不可见"标识、角色权限实为三类（主管理员 / 管理员 / 基础权限成员）。

## 四、可复用的判据（沉淀成动作）

1. **永远先拿字数统计当分母**，抓完立刻比对。
2. **抓不全时先查 `visibilityState`**，再谈其他手段。
3. **任何"空章节"都必须截图验证**，截图有内容就是图片承载。
4. **下载文档内图片不能用 curl**（0 字节），必须走浏览器通道。
5. **逐图解读要专门看"评审批注"** —— 未闭环项全在那里，正文一个字都不会提。
