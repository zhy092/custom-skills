# 知识拆解方法论

把一本书拆成播客素材，本质是三件事：**读懂结构 → 提炼可传递的知识单元 → 按听觉逻辑重组**。
逐块精读时的产出质量决定成片质量，这一步不能省。

---

## 一、三遍读法

### 第 1 遍：结构侦查（只读 `structure.json`）

不读正文。先回答：

- 这是什么类型的书？（见第五节「按书型调整」）
- 作者的核心主张是什么？（常在前言/序/首章/结论章）
- 章节标题之间是什么关系？递进 / 并列 / 总分 / 时间线？
- 哪些章是"肉"，哪些是"注水"？（字数畸小的章常是过渡，畸大的常是核心）

产出：一段 200 字以内的全书判断，写进 `notes/00_recon.md`。

### 第 2 遍：逐块精读（读 `chunks/chunk_XXX.md`）

**按 `manifest.json` 的 `reading_batches` 分批读，一批读完立刻写笔记再读下一批。**
绝不一次性把所有 chunk 读进上下文——那会导致后半本书被稀释成模糊印象。

每块产出一份局部笔记 `notes/chunk_XXX.md`：

```markdown
## chunk 007 · 第3章 反脆弱的三元结构

### 核心论断
- 系统对波动的响应分三类：脆弱（受损）、强韧（不变）、反脆弱（受益）

### 概念定义
- **反脆弱 (antifragile)**: 原文"从冲击中获益…在波动中成长"。注意：不等于"强韧"，
  作者反复强调这是新造词，因为语言里缺这个概念。

### 因果 / 模型
- 小损失高频暴露 → 系统获得信息 → 局部失败换全局适应
- 反例：为消除小波动而干预 → 风险累积到尾部 → 一次性崩溃

### 证据与案例
- 航空业：每次空难后规则收紧，整体安全性上升（行业反脆弱、个体脆弱）
- 银行业：救助消除小破产 → 2008 系统性崩塌

### 反直觉点 ⭐
- "稳定"本身可能是危险信号。长期没有小波动的系统，正在积累尾部风险。

### 金句（可直接引用）
- "风会熄灭蜡烛，却能使火越烧越旺。"

### 可执行
- 检查你的系统里，哪些"平稳指标"其实是干预的产物

### 存疑 / 局限
- 作者未量化"多小的波动算有益"，判定标准偏主观
```

分类不必强行填满——某块只有案例没有金句，就只写案例。**空着比编造好。**

### 第 3 遍：汇总成知识图谱

把所有 `notes/chunk_*.md` 读回来（笔记总量远小于原文，这时可以整体读），
合成 `outline.json`：

```json
{
  "book": {"title": "", "author": "", "language": "zh", "type": "论述型"},
  "thesis": "全书用一句话概括的核心主张",
  "why_it_matters": "对听众而言，这本书解决什么问题",
  "knowledge_points": [
    {
      "id": "kp01",
      "name": "反脆弱的三元结构",
      "type": "concept",
      "one_liner": "一句话说清",
      "explanation": "150-300 字展开",
      "evidence": ["案例A", "数据B"],
      "counterintuitive": "反直觉在哪（没有就留空）",
      "quotes": ["原文金句"],
      "actionable": ["可执行动作"],
      "source_chunks": [7, 8],
      "weight": 5,
      "depends_on": []
    }
  ],
  "threads": [
    {"name": "主题线名称", "kp_ids": ["kp01", "kp05"], "narrative": "这条线讲什么故事"}
  ],
  "critique": "全书的局限、争议、被批评之处",
  "not_covered": "书里没讲但听众会问的"
}
```

字段说明：

- `type`: `concept` 概念 / `model` 模型 / `method` 方法 / `evidence` 证据 / `story` 故事 / `principle` 原则
- `weight`: 1–5，重要度。决定它在哪一集、占多少时长
- `depends_on`: 前置知识点 id。**决定分集顺序** —— 依赖项必须排在前面
- `threads`: 主题线，是分集的直接依据

## 二、知识点的质量红线

一个知识点必须同时满足：

1. **可脱离原书独立成立** —— 听众没读过书也能听懂
2. **有具体支撑** —— 至少一个案例、数据或原文引用。只有抽象论断的，是废点
3. **能被复述** —— 听完一周后还能跟朋友讲出来的，才是真知识点

会被判为废点的典型：

| 废点 | 问题 | 修好 |
|---|---|---|
| "作者强调沟通很重要" | 正确的废话 | "作者发现：反馈里的'但是'会抹掉前半句所有正面信息，改用'而且'留存率提升 3 倍" |
| "第 5 章讲了三种方法" | 复述目录 | 直接讲那三种方法各自解决什么、怎么选 |
| "这本书很有启发" | 评价而非知识 | 删掉 |

## 三、分集策略

**按主题线（threads）分集，不要按章节顺序分集。**
书的章节顺序服务于阅读逻辑，播客要服务于听觉逻辑——一集一个核心问题。

### 集数与时长

| 全书字数 | 建议集数 | 单集时长 |
|---|---|---|
| < 5 万字 | 2–3 集 | 12–18 分钟 |
| 5–15 万字 | 4–6 集 | 15–22 分钟 |
| 15–30 万字 | 6–10 集 | 18–25 分钟 |
| > 30 万字 | 10–15 集 | 18–25 分钟 |

超过 25 分钟完播率断崖下跌。宁可多切一集。

### 标准编排

1. **第 1 集：总览 + 钩子** —— 全书主张、为什么值得听、后面每集讲什么。这集决定用户会不会听第二集
2. **中间集：一集一条主题线** —— 每集 3–5 个知识点，围绕一个核心问题
3. **最后一集：批判与应用** —— 局限、争议、跨界联系、可执行清单

### 单集的知识点密度

- 15 分钟 ≈ 3 个知识点 + 2 个案例
- 20 分钟 ≈ 4 个知识点 + 3 个案例
- **超过 5 个知识点的一集必然过载**，听众记不住

写进 `episodes.json`：

```json
{
  "series_title": "《反脆弱》拆书电台",
  "language": "zh",
  "episodes": [
    {
      "id": "ep01",
      "title": "为什么'稳定'是最危险的假象",
      "core_question": "这一集要回答的那个问题",
      "kp_ids": ["kp01", "kp03", "kp07"],
      "target_minutes": 18,
      "hook": "开场 30 秒用什么抓住听众",
      "takeaway": "听完能带走的一句话"
    }
  ]
}
```

## 四、语言处理

原书语言与输出语言解耦：

- **默认输出中文**，不论原书是什么语言
- 翻译时保留**原文关键术语**首次出现的原词：`反脆弱（antifragile）`
- 金句引用给**原文 + 译文**，脚本里只念译文，原文放 shownotes
- 人名地名用通行译名；无通行译名时保留原文
- 若用户要求输出原书语言，全流程（笔记可用中文，但 `outline.json` 的
  `one_liner`/`explanation`/脚本正文必须是目标语言）

## 五、按书型调整拆法

| 书型 | 特征 | 拆解重点 | 常见坑 |
|---|---|---|---|
| **论述型**（思想/社科） | 有中心论点，层层论证 | 论证链条、反驳、边界条件 | 只提结论不提论证过程 |
| **工具型**（方法/技能） | 步骤、清单、模板 | 完整可执行流程 + 失败模式 | 漏掉前置条件，听众照做失败 |
| **叙事型**（历史/纪实） | 时间线、人物、事件 | 因果转折点、决策时刻 | 变成流水账复述剧情 |
| **传记** | 一个人的一生 | 关键抉择 + 时代约束 | 只讲成功不讲运气与代价 |
| **学术** | 文献、方法、数据 | 研究问题、方法创新、结论强度 | 不交代样本与局限就下结论 |
| **文学/小说** | 情节、人物、意象 | 主题、结构技法、时代语境 | 剧透；用"知识点"框架肢解文学性 |
| **合集/访谈** | 篇目独立 | 先归类再抽共性 | 按原书顺序逐篇复述 |

**小说特别注意**：不要按"知识点"拆。改用「主题 / 人物弧光 / 结构技法 / 时代背景 / 争议解读」
五个维度，并在每集开头声明剧透程度。

## 六、常见失败模式

1. **贪多** —— 想把所有内容塞进播客。原则：**宁可讲透 3 个点，不要划过 30 个点**
2. **失衡** —— 前三章讲得细，后面越来越糙。逐块笔记能有效防止这点，别跳过
3. **失真** —— 把作者的推测说成定论。笔记里标注 `作者认为` / `研究显示` / `作者推测`
4. **无我** —— 只复述不评价。最后一集的批判部分是价值所在，不要省
5. **孤岛** —— 不跟听众已知的东西建立连接。好的拆书会说"这跟 XX 是一回事"
